Web dizajn - Priprema za ispit

Kompletni odgovori na teorijska pitanja i rješenja praktičnih zadataka.

1. Uvod i obrada slike

1. Koji su elementi web dizajna?
Elementi web dizajna uključuju: layout (raspored), boje, tipografiju (fontove), slike, grafiku, navigaciju, interaktivne elemente, animacije, sadržaj (tekst, video, audio) i korisničko iskustvo (UX).
2. Što je World Wide Web?
World Wide Web (WWW) je sustav međusobno povezanih hipertekstualnih dokumenata koji se prenose putem interneta. Omogućuje pristup web stranicama putem web preglednika koristeći HTTP/HTTPS protokole.
3. Koja je razlika između hypermedijskih dokumenata i hyperveza?
Hipermedijski dokument je dokument koji sadrži više vrsta medija (tekst, slike, audio, video) povezanih hipervezama. Hiperveza (link) je veza koja vodi od jednog dokumenta do drugog ili unutar istog dokumenta. Dakle, hiperveza je element unutar hipermedijskog dokumenta.
4. Kako radi HTTP?
HTTP (HyperText Transfer Protocol) radi na principu zahtjeva (request) i odgovora (response). Klijent (web preglednik) šalje HTTP zahtjev serveru, server obrađuje zahtjev i vraća HTTP odgovor koji sadrži statusni kod i traženi sadržaj (HTML, slike, itd.).
5. Koja je razlika između HTTPS i HTTP protokola?
HTTPS (HyperText Transfer Protocol Secure) je sigurna verzija HTTP-a koja koristi SSL/TLS enkripciju za zaštitu podataka koji se prenose između klijenta i servera. HTTP prenosi podatke u čistom tekstu, dok HTTPS osigurava povjerljivost i integritet podataka.
6. Što je HTTP metoda (method) i koje sve postoje?
HTTP metoda je naredba koja se šalje serveru kako bi se označila željena akcija. Najčešće metode su: GET (dohvat podataka), POST (slanje podataka), PUT (ažuriranje), DELETE (brisanje), HEAD (dohvat zaglavlja), PATCH (djelomično ažuriranje), OPTIONS (dozvoljene metode).
7. Što predstavljaju HTTP status kodovi (1xx do 5xx)?
  • 1xx (Informacijski): Zahtjev primljen, nastavlja se proces.
  • 2xx (Uspjeh): Zahtjev uspješno obrađen (npr. 200 OK).
  • 3xx (Preusmjeravanje): Potrebna dodatna akcija za dovršetak zahtjeva (npr. 301 Moved Permanently).
  • 4xx (Greška klijenta): Zahtjev sadrži grešku (npr. 404 Not Found).
  • 5xx (Greška servera): Server nije uspio obraditi zahtjev (npr. 500 Internal Server Error).
8. Što je URL i od čega se sastoji?
URL (Uniform Resource Locator) je jedinstvena adresa koja identificira lokaciju resursa na internetu. Sastoji se od: protokola (npr. https://), domene (npr. www.example.com), porta (opcionalno), putanje do datoteke (npr. /folder/stranica.html), upitnog niza (query string, npr. ?id=1) i fragmenta (npr. #sekcija).
9. Što je web browser?
Web browser (web preglednik) je softver koji omogućuje korisnicima pristup, pretraživanje i prikaz web stranica. Interpretira HTML, CSS i JavaScript te prikazuje web sadržaj. Primjeri: Chrome, Firefox, Safari, Edge.
10. Koja je razlika između browser enginea i JavaScript enginea?
Browser engine (npr. Blink, Gecko, WebKit) prevodi HTML i CSS u vizualni prikaz na ekranu. JavaScript engine (npr. V8, SpiderMonkey) izvršava JavaScript kod. Browser engine upravlja renderiranjem, dok JavaScript engine upravlja izvršavanjem skripti.
11. Koji su najčešći preglednici koji se koriste?
Google Chrome, Mozilla Firefox, Microsoft Edge, Safari i Opera.
12. Koja je razlika između aditivnog i subratkivnog modela boje?
Aditivni model (RGB) koristi se za emisiju svjetlosti (ekrani). Miješanjem crvene, zelene i plave dobiva se bijela. Subratkivni model (CMYK) koristi se za ispis na papiru. Miješanjem cijan, magente, žute i crne dobiva se crna.
13. Razlika između heksadekadskog i RGB zapisa boje?
Heksadekadski zapis (npr. #FF0000) koristi 6 znakova (0-9, A-F) za prikaz RGB vrijednosti. RGB zapis (npr. rgb(255, 0, 0)) koristi decimalne vrijednosti od 0 do 255 za svaku komponentu. Oba prikazuju istu boju, ali na različit način.
14. Koje su primarne, a koje sekundarne boje?
Primarne boje (aditivni model): crvena, zelena, plava. Sekundarne boje (aditivni model): cijan (zelena+plava), magenta (crvena+plava), žuta (crvena+zelena). U subratkivnom modelu primarne su cijan, magenta, žuta, a sekundarne crvena, zelena, plava.
15. Koje kategorije fontova postoje?
Serif (npr. Times New Roman), Sans-serif (npr. Arial), Monospace (npr. Courier New), Cursive (npr. Comic Sans), Fantasy (npr. Impact).
16. Koja je razlika između fonta, font family i glypha?
Font family je skup fontova koji dijele zajednički dizajn (npr. Arial). Font je specifična varijanta unutar obitelji (npr. Arial Bold, Arial Italic). Glyph je pojedinačni vizualni znak unutar fonta (npr. slovo 'A', broj '1').
17. Koja je razlika između vektorske i rasterske grafike?
Vektorska grafika koristi matematičke formule (točke, linije, krivulje) za prikaz slike i može se skalirati bez gubitka kvalitete. Rasterska grafika sastoji se od piksela i gubi kvalitetu pri povećanju.
18. Koje su prednosti vektorske, a koje rasterske grafike?
Vektorska: beskonačno skaliranje, male datoteke, idealna za logotipe i ikone. Rasterska: bogatstvo detalja, idealna za fotografije, široka podrška.
19. Koji se formati datoteka najčešće koriste za spremanje vektorskih, a koji za spremanje rasterskih grafičkih datoteka?
Vektorski: SVG, AI, EPS, PDF. Rasterski: JPEG, PNG, GIF, BMP, TIFF, WebP.
20. Koji su najčešći strukturni elementi web stranica?
Header, navigacija, glavni sadržaj (main), bočna traka (aside), podnožje (footer), sekcije (section), članci (article).
21. Što je wireframing?
Wireframing je proces izrade grubog, pojednostavljenog nacrta web stranice ili aplikacije koji prikazuje raspored elemenata, navigaciju i funkcionalnost bez detalja dizajna (boje, slike).

VJEŽBA: Figma

Zadatak: Kreirajte novi dokument u Figmi. Dodajte i oblikujte tekst (lorem ipsum). Promijenite font, veličinu, prored i razmak između znakova. Nacrtajte nekoliko vektorskih elemenata. Dodajte im različite obrube i ispune te sjenu. Dodajte sliku. Izvezite elemente kao PNG sliku i spremite ih na računalo. Grupirajte ih te izvezite i spremite grupu elemenata kao PDF na računalo.

Rješenje (upute):

  1. Otvorite Figmu i kreirajte novi dizajn file.
  2. Odaberite Text tool (T) i nacrtajte tekstualni okvir. Zalijepite Lorem Ipsum tekst.
  3. U desnom panelu promijenite font (npr. Inter), veličinu (npr. 16), line-height (npr. 1.5) i letter-spacing (npr. 1px).
  4. Koristite Rectangle, Ellipse ili Pen tool za crtanje vektorskih elemenata.
  5. Za svaki element u desnom panelu postavite Fill (boja), Stroke (obrub) i Effects (sjena - Drop shadow).
  6. Odaberite Frame tool i nacrtajte okvir, zatim povucite sliku u Figmu ili koristite Place Image.
  7. Odaberite elemente koje želite izvesti, desni klik > Export > odaberite PNG > Export.
  8. Grupirajte elemente (Ctrl+G), desni klik > Export > odaberite PDF > Export.

2. HTML

1. Kakav jezik je HTML (čemu služi)?
HTML (HyperText Markup Language) je jezik za označavanje (markup language), a ne programski jezik. Služi za struktuiranje sadržaja na web stranicama.
2. Kako se piše HTML, od čega je sastavljen?
HTML se piše pomoću oznaka (tagova) koje se sastoje od početne i završne oznake (npr. <p> </p>). Sastoji se od elemenata, atributa i sadržaja. Osnovna struktura uključuje <!DOCTYPE html>, <html>, <head> i <body>.
3. Čemu služe atributi oznake i koje vrste atributa postoje?
Atributi pružaju dodatne informacije o elementu. Postoje globalni atributi (npr. id, class, style) i specifični atributi (npr. href za <a>, src za <img>).
4. Što su HTML entiteti?
HTML entiteti su posebni kodovi koji se koriste za prikaz rezerviranih znakova ili znakova koji nisu dostupni na tipkovnici (npr. &lt; za <, &amp; za &, &copy; za ©).
5. Koje ekstenzije imaju HTML dokumenti?
.html i .htm
6. Gdje se nalazi sadržaj u HTML elementu?
Sadržaj se nalazi između početne i završne oznake elementa (npr. <p>Ovo je sadržaj</p>).
7. Što sadrži head dio HTML dokumenta?
Head sadrži metapodatke: naslov dokumenta (<title>), charset, viewport, linkove na CSS datoteke, skripte, meta opise, favicon.
8. Što su block elementi? Navedite nekoliko block elemenata.
Block elementi zauzimaju punu širinu i počinju u novom redu. Primjeri: <div>, <p>, <h1>-<h6>, <ul>, <ol>, <li>, <header>, <footer>, <section>.
9. Što su inline elementi? Navedite nekoliko inline elemenata.
Inline elementi zauzimaju samo onoliko širine koliko im je potrebno i ne prekidaju tok teksta. Primjeri: <span>, <a>, <img>, <strong>, <em>, <br>.
10. Koje oznake koristimo za označavanje naslova, paragrafa, slike, poveznice, podebljanog teksta, nakošenog teksta, prekriženog teksta, ubačenog teksta, indeksa i eksponenta?
  • Naslov: <h1> do <h6>
  • Paragraf: <p>
  • Slika: <img>
  • Poveznica: <a>
  • Podebljano: <strong> ili <b>
  • Nakošeno: <em> ili <i>
  • Prekriženo: <del> ili <s>
  • Ubačeno: <ins> ili <u>
  • Indeks: <sub>
  • Eksponent: <sup>
11. Koje liste postoje u HTML-u? Kako se označavaju liste i njihovi elementi?
Postoje neuređene liste (<ul>), uređene liste (<ol>) i liste opisa (<dl>). Elementi lista: <li> za ul/ol, <dt> za pojam i <dd> za opis.
12. Što su strukturni elementi i čemu služe?
Strukturni elementi služe za definiranje osnovne strukture web stranice. Primjeri: <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>.
13. Što su semantički elementi i čemu služe?
Semantički elementi jasno opisuju svoju svrhu i sadržaj, što pomaže pretraživačima i čitačima ekrana. Primjeri: <header>, <nav>, <main>, <article>, <section>, <aside>, <footer>, <figure>, <figcaption>.
14. Objasni obojane elemente ovog HTML elementa: <a href="https://google.com" target="_blank">Google</a>
  • href - atribut koji definira URL odredišta poveznice.
  • <a></a> - oznaka za hipervezu (anchor).
  • Google - tekst koji je vidljiv korisniku i na koji se klikom aktivira poveznica.
  • target - atribut koji određuje gdje će se otvoriti poveznica. Vrijednosti: _blank (novi tab), _self (isti tab), _parent, _top.
15. Koja je razlika između apsolutne i relativne adrese?
Apsolutna adresa sadrži puni URL (npr. https://www.example.com/stranica.html). Relativna adresa odnosi se na lokaciju relativno u odnosu na trenutnu stranicu (npr. /stranica.html ili ../slika.jpg).
16. Kako se označavaju poveznice na e-mail adresu i na telefonski broj?
  • E-mail: <a href="mailto:netko@example.com">Pošalji email</a>
  • Telefon: <a href="tel:+38512345678">Pozovi</a>
17. Što je sidro?
Sidro (anchor) je poveznica unutar iste stranice koja vodi na određeni dio stranice. Koristi se pomoću atributa id i href="#id".
18. Pomoću koje oznake dodajemo sliku u HTML? Koje atribute oznaka slike sadrži?
Slika se dodaje pomoću <img> oznake. Obavezni atributi: src (putanja do slike) i alt (alternativni tekst). Ostali: width, height, title, loading.
19. Kako funkcioniraju oznake figure i figcaption?
<figure> služi za grupiranje medijskog sadržaja (slike, dijagrami, kod). <figcaption> dodaje opis ili legendu tom sadržaju. Primjer: <figure><img src="slika.jpg"><figcaption>Opis slike</figcaption></figure>.
20. Kako se označava audio ili video sadržaj?
Audio: <audio controls><source src="audio.mp3" type="audio/mpeg"></audio>. Video: <video controls width="500"><source src="video.mp4" type="video/mp4"></video>.
21. Što sadrže HTML tablice? Koje oznake se koriste za tablice, ćelije i redove?
Tablice sadrže retke i ćelije. Oznake: <table> za tablicu, <tr> za redak, <td> za ćeliju, <th> za zaglavlje ćelije, <thead>, <tbody>, <tfoot> za sekcije.
22. Pomoću kojih atributa ćelija u tablici se može protezati u više redaka i stupaca?
colspan za spajanje stupaca, rowspan za spajanje redaka.
23. Koje semantičke elemente koristimo za označavanje tablica?
<thead>, <tbody>, <tfoot>, <caption>, <colgroup>, <col>.
24. Čemu služi HTML obrazac?
HTML obrazac (form) služi za prikupljanje korisničkih podataka i njihovo slanje na server na obradu.
25. Koji su najčešći elementi za izradu obrazaca?
<input>, <textarea>, <select>, <option>, <button>, <label>, <fieldset>, <legend>.
26. Čemu služe metapodaci i u kojem dijelu HTML dokumenta se nalaze?
Metapodaci pružaju informacije o dokumentu (opis, ključne riječi, autor, charset). Nalaze se unutar <head> elementa.
27. Koji su najčešće korišteni metapodaci?
charset, viewport, description, keywords, author, robots.
28. Čemu služi "id" atribut unutar HTML oznake?
id atribut jedinstveno identificira element na stranici. Koristi se za CSS stiliziranje, JavaScript manipulaciju i sidrišta.
29. Čemu služi "action" atribut unutar oznake "form"?
action atribut definira URL na koji će se poslati podaci iz obrasca nakon slanja.
30. Čemu služi "alt" atribut unutar oznake "img"?
alt atribut pruža alternativni tekst koji se prikazuje ako slika ne može biti učitana. Također je važan za pristupačnost i SEO.

Nakon tog naslova dodajte listu koja će sadržavati sidra na pojedine naslove razine 2, 3 i 4 niže u dokumentu. Zatim dodajte tablicu prema uputama, video, formu i kontakt poveznice.

    <title>Moj HTML dokument</title>
