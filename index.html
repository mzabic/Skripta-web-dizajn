1. UVOD I OBRADA SLIKE

Koji su elementi web dizajna?
Layout (raspored), tipografija, boje, slike/grafika, navigacija, sadržaj i interaktivnost.
Što je world wide web?
Mrežni sustav međusobno povezanih hipertekstualnih dokumenata kojima se pristupa putem interneta pomoću web preglednika.
Koja je razlika između hypermedijskih dokumenata i hyperveza?
Hypermedijski dokumenti sadrže različite medije (tekst, slike, zvuk, video), dok su hyperveze (poveznice/linkovi) elementi koji vode na druge dokumente ili resurse.
Kako radi http?
Klijent (browser) šalje HTTP zahtjev serveru, a server obrađuje zahtjev i vraća HTTP odgovor koji sadrži traženi sadržaj ili šifru pogreške.
Koja je razlika između https i http protokola?
HTTPS koristi SSL/TLS enkripciju za siguran i šifriran prijenos podataka, dok HTTP prenosi podatke u čistom, nešifriranom tekstu.
Što je http metoda (method) i koje sve postoje?
HTTP metoda označava akciju koju klijent želi izvršiti na resursu. Najčešće su: GET (dohvaćanje), POST (slanje podataka), PUT (ažuriranje), DELETE (brisanje) i PATCH (djelomična izmjena).
Što predstavljaju http status kodovi (1xx do 5xx)?
1xx: Informativni kodovi
2xx: Uspješne akcije (npr. 200 OK)
3xx: Preusmjeravanja (npr. 301 Moved Permanently)
4xx: Klijentske pogreške (npr. 404 Not Found)
5xx: Poslužiteljske pogreške (npr. 500 Internal Server Error)
Što je URL i od čega se sastoji?
URL (Uniform Resource Locator) je adresa resursa na internetu. Sastoji se od: protokola (https://), domene/domenskog imena (example.com), porta (:443), staze (/folder/index.html) i parametara (?id=1).
Što je web browser?
Softverska aplikacija za dohvaćanje, interpretaciju i prikazivanje HTML/CSS/JS dokumenata s interneta.
Koja je razlika između browser enginea i JavaScript enginea?
Browser engine rendersira HTML i CSS te gradi vizualni prikaz stranice, dok JavaScript engine prevodi i izvršava JavaScript kôd.
Koji su najčešći preglednici koji se koriste?
Google Chrome, Mozilla Firefox, Apple Safari, Microsoft Edge.
Koja je razlika između aditivnog i subratkivnog modela boje?
Aditivni model (RGB) zbraja svjetlost i koristi se za ekrane (miješanjem svih nastaje bijela). Subtraktivni model (CMYK) oduzima svjetlost miješanjem pigmenata u tisku (miješanjem nastaje crna).
Razlika između heksadekadskog i RGB zapisa boje?
RGB zapis koristi dekadske vrijednosti od 0 do 255 za crvenu, zelenu i plavu (npr. rgb(255, 0, 0)), dok heksadekadski zapis koristi bazu 16 i format od 6 znakova (npr. #FF0000).
Koje su primarne, a koje sekundarne boje?
Primarne aditivne boje na ekranu su crvena, zelena i plava (RGB). Sekundarne boje nastaju miješanjem dviju primarnih (npr. žuta, cijan, magenta).
Koje kategorije fontova postoje?
Serif (sa kukičicama/serifima), Sans-serif (bez serifa), Monospace (fiksna širina slova), Script (rukopisni) i Display/Decorative (ukrasni).
Koja je razlika između fonta, font family i glypha?
Font family je obitelj stilova (npr. Arial), font je konkretna inačica s definiranom veličinom i težinom (npr. Arial Bold 12pt), a glyph je pojedinačni grafički prikaz određenog znaka ili slova.
Koja je razlika između vektorske i rasterske grafike?
Vektorska grafika sastoji se od matematičkih linija i oblika pa se može neograničeno skalirati bez gubitka kvalitete. Rasterska grafika sastoji se od fiksnog broja piksela te se pri povećanju gubi kvaliteta.
Koje su prednosti vektorske, a koje rasterske grafike?
Prednosti vektorske: skalabilnost bez gubitka kvalitete i manje datoteke za oblike/logotipe. Prednosti rasterske: prikaz složenih detalja, tonova i gradijenata idealnih za fotografije.
Koji se formati datoteka najčešće koriste za spremanje vektorskih, a koji za rasterske?
Vektorski: SVG, EPS, AI, PDF. Rasterski: JPEG, PNG, GIF, WEBP.
Koji su najčešći strukturni elementi web stranica?
Header (zaglavlje), Navigation (izbornik), Main content (glavni sadržaj), Sidebar/Aside (bočna traka) i Footer (podnožje).
Što je wireframing?
Proces izrade jednostavnog vizualnog nacrta ili skice izgleda i strukture web stranice prije same izrade dizajna i pisanja koda.
Upute za Vježbu (Figma):

U Figmi kreirajte novi Frame. Pomoću alata Text (T) unesite tekst i promijenite mu obitelj fonta, veličinu, line-height (prored) i letter-spacing. Nacrtajte pravokutnik/krug pomoću Shape Tools, dodajte Fill (ispunu), Stroke (obrub) i Drop Shadow efekt. Ubacite sliku (Place Image). Odaberite element, idite na Export na dnu desnog panela i izvezite kao PNG. Grupirajte elemente (Ctrl+G / Cmd+G) te izvezite cijelu grupu kao PDF.

2. HTML

Kakav jezik je html (čemu služi)?
HTML (HyperText Markup Language) je jezik za označavanje koji služi za definiranje strukture i sadržaja web stranica.
Kako se piše html, od čega je sastavljen?
Piše se pomoću HTML oznaka (tagova) unutar oštrih zagrada, najčešće u parovima: <tag>sadržaj</tag>.
Čemu služe atributi oznake i koje vrste atributa postoje?
Atributi pružaju dodatne informacije o elementu. Postoje globalni atributi (npr. id, class, style) i specifični atributi (npr. src za sliku, href za poveznicu).
Što su html entiteti?
HTML entiteti su posebni nizovi znakova koji se koriste za prikaz rezerviranih znakova (npr. &lt; za <) ili nevidljivih znakova (npr. &nbsp; za razmak).
Koje ekstenzije imaju html dokumenti?
.html ili .htm.
Gdje se nalazi sadržaj u html elementu?
Između početne i završne oznake elementa.
Što sadrži head dio html dokumenta?
Sadrži metapodatke, naslov stranice (<title>), poveznice na CSS datoteke, JS skripte, definiciju kodnog rasporeda i prilagodbe za ekrane.
Što su block elementi? Navedite nekoliko block elemenata.
Blok elementi uvijek započinju u novom redu i zauzimaju čitavu dostupnu širinu. Primjeri: <div>, <p>, <h1>-<h6>, <ul>, <li>, <form>, <article>.
Što su inline elementi? Navedite nekoliko inline elemenata.
Inline elementi zauzimaju samo onoliko širine koliko je potrebno za njihov sadržaj i ne prelaze u novi red. Primjeri: <span>, <a>, <img>, <strong>, <em>.
Koje oznake koristimo za označavanje naslova, paragrafa, slike, poveznice, podebljanog teksta, nakošenog teksta, prekriženog teksta, ubačenog teksta, indeksa i eksponenta?
Naslovi: <h1> do <h6> | Paragraf: <p> | Slika: <img> | Poveznica: <a>
Podebljano: <strong> ili <b> | Nakošeno: <em> ili <i> | Prekriženo: <del>
Ubačeno: <ins> | Indeks: <sub> | Eksponent: <sup>
Koje liste postoje u html-u? Kako se označavaju liste i njihovi elementi?
Nesortirane liste (<ul>), sortirane liste (<ol>) i opisne liste (<dl>). Elementi u <ul> i <ol> označavaju se s <li>.
Što su strukturni elementi i čemu služe?
Elementi koji definiraju osnovni izgled i raspored sekcija unutar web stranice (npr. <div>, <header>, <footer>).
Što su semantički elementi i čemu služe?
Elementi koji jasno opisuju svoje značenje pregledniku i tražilicama (npr. <article>, <nav>, <section>, <aside>), što poboljšava pristupačnost i SEO.
Objasni obojane elemente ovog html elementa: <a href="https://google.com" target="_blank">Google</a>
<a></a> je HTML oznaka za hipervezu (sidro).
href="..." je atribut koji specificira ciljnu web adresu.
target="_blank" je atribut koji otvara vezu u novom prozoru/kartici.
"Google" je vidljivi tekst poveznice.
Što je href i čemu služi?
Atribut unutar <a> oznake koji definira odrediše (URL ili sidro) na koje veza vodi.
Čemu služi target atribut i koje vrste vrijednosti postoje?
Definira gdje će se otvoriti poveznica. Vrijednosti: _self (u istom prozoru, zadano), _blank (u novom kartici), _parent, _top.
Koja je razlika između apsolutne i relativne adrese?
Apsolutna adresa sadrži punu web adresu (npr. https://example.com/slika.jpg), dok relativna adresa definira putanju u odnosu na trenutnu lokaciju datoteke (npr. images/slika.jpg).
Kako se označavaju poveznice na e-mail adresu i na telefonski broj?
E-mail: <a href="mailto:ime@domena.com">Pošalji e-mail</a> | Telefon: <a href="tel:+3851234567">Pozovi</a>.
Što je sidro?
Poveznica koja vodi na određeno mjesto na istoj web stranici pomoću id atributa (npr. href="#naslov2").
Pomoću koje oznake dodajemo sliku u html? Koje atribute sadrži?
Pomoću oznake <img>. Glavni atributi su src (izvor slike) i alt (zamjenski tekst).
Kako funkcioniraju oznake figure i figcaption?
<figure> se koristi za obuhvaćanje samostalnog sadržaja (npr. slike ili dijagrama), a <figcaption> unutar njega definira naslov ili opis tog sadržaja.
Kako se označava audio ili video sadržaj?
Pomoću oznaka <audio controls> i <video controls> u kombinaciji s <source src="..." type="..."> pod-elementima.
Što sadrže html tablice? Koje oznake se koriste za tablice, ćelije i redove?
Tablice sadrže redove i ćelije. Oznake: <table> (tablica), <tr> (red), <td> (ćelija podataka), <th> (ćelija zaglavlja).
Pomoću kojih atributa ćelija u tablici se može protezati u više redaka i stupaca?
colspan (spajanje stupaca) i rowspan (spajanje redaka).
Koji semantičke elemente koristimo za označavanje tablica?
<thead> (zaglavlje tablice), <tbody> (tijelo tablice) i <tfoot> (podnožje tablice).
Čemu služi html obrazac?
Služi za prikupljanje unosa korisnika i slanje tih podataka na poslužitelj radi obrade.
Koji su najčešći elementi za izradu obrazaca?
<form>, <input>, <textarea>, <select>, <option>, <label>, <button>.
Čemu služe metapodaci i u kojem dijelu html dokumenta se nalaze?
Pružaju informacije o dokumentu preglednicima i tražilicama. Nalaze se unutar <head> dijela.
Koji su najčešće korišteni metapodaci?
<meta charset="UTF-8">, <meta name="viewport" content="width=device-width, initial-scale=1.0">, <meta name="description" content="...">.
Čemu služe id, action i alt atributi?
id: Jedinstveni identifikator elementa na stranici.
action: URL na koji se šalju podaci obrasca nakon slanja.
alt: Opis slike ako se slika ne učita ili za čitače ekrana.

3. CSS

Je li css programski jezik (ako ne, koji je)?
CSS nije programski jezik nego jezik stilskih pravila (style sheet language). Programski jezici su npr. JavaScript, Python, PHP.
Čemu služi stilski jezik?
Služi za definiranje vizualnog izgleda, rasporeda i stiliziranja dokumenata napisanih u jeziku za označavanje (HTML).
Što su liste stilskih pravila?
Nizovi stilskih deklaracija u kojima su zadana svojstva i vrijednosti za odabrane HTML selektore.
Što znači kaskadna primjena stilskih pravila?
Znači da se stilovi primjenjuju po hijerarhiji i specifičnosti. Pravila definirana kasnije ili s većom specifičnošću pregažaju ranije izračunate stilove.
Kako se piše css pravilo? Kako odvajamo više css svojstava u istom pravilu?
Sintaksa: selektor { svojstvo: vrijednost; }. Više svojstava odvaja se točkom-zarezom (;).
Koju ekstenziju imaju css datoteke?
.css.
Koja su 3 načina na koje možemo povezati i pisati css pravila u html dokumentu?
1. Vanjski CSS (<link rel="stylesheet" href="style.css">)
2. Unutarnji CSS (<style> u <head>)
3. Linijski/Inline CSS (style="..." atribut).
Kako pišemo selektore za: sve oznake, specifičnu oznaku, po ID-u, po klasi?
Sve oznake: * { ... }
Specifična oznaka: p { ... } ili div { ... }
Po ID-u: #mojID { ... }
Po klasi: .mojaklasa { ... }
Čemu služi selektor pseudo klase i što omogućava pseudo klasa :hover?
Pseudo klase definiraju stilove za posebno stanje elementa. :hover definira stilove kada korisnik prijeđe mišem preko elementa.
Što su css kombinatori i kako djeluju sledeći selektori: div span, div > span, div + span, div ~ span?
div span: Svi span elementi unutar div-a (potomci).
div > span: Svi span elementi koji su izravni potomci div-a.
div + span: Prvi span element koji se nalazi neposredno nakon div-a.
div ~ span: Svi span
