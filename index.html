1. Uvod i Obrada Slike

  • Elementi web dizajna: Izgled (layout), boje, tipografija, grafika/slike, navigacija i sadržaj.
  • World Wide Web (WWW): Globalni sustav međusobno povezanih hipertekstualnih dokumenata kojima se pristupa putem interneta koristeći HTTP/HTTPS protokole.
  • Hypermedijski dokumenti vs. Hyperveze: Hipermedijski dokumenti sadrže kombinaciju teksta, slika, zvuka i videa, dok su hiperveze (linkovi) veze koje spajaju te dokumente.
  • HTTP rad: Protokol po principu klijent-poslužitelj. Klijent (preglednik) šalje HTTP zahtjev poslužitelju, a poslužitelj vraća HTTP odgovor sa sadržajem.
  • HTTP vs. HTTPS: HTTPS je sigurna verzija HTTP-a koja koristi SSL/TLS enkripciju za zaštitu prijenosa podataka.
  • HTTP metode: GET (dohvaćanje), POST (slanje), PUT (ažuriranje), DELETE (brisanje).
  • HTTP Status Kodovi: 1xx (Informacija), 2xx (Uspjeh - npr. 200 OK), 3xx (Preusmjeravanje), 4xx (Klijentska pogreška - npr. 404), 5xx (Poslužiteljska pogreška).
  • URL i dijelovi: Jedinstvena web adresa (Protokol + Domena + Priključak + Putanja + Parametri).
  • Browser Engine vs. JS Engine: Browser engine renderira HTML/CSS (npr. Blink, Gecko), a JS engine izvršava JavaScript kod (npr. V8, SpiderMonkey).
  • Aditivni vs. Suptraktivni model boja: Aditivni (RGB) miješa svjetlost (za ekrane), suptraktivni (CMYK) miješa pigmente/boje (za tisak).
  • Heksadekadski vs. RGB zapis: RGB koristi vrijednosti 0-255 (npr. rgb(255,0,0)), dok heksadekadski koristi 6 hex znakova (npr. #FF0000).
  • Vektorska vs. Rasterska grafika: Raster je građen od piksela i gubi kvalitetu pri povećanju (JPG, PNG); Vektor koristi matematičke formule i skalabilan je bez gubitka kvalitete (SVG, AI, PDF).

2. HTML

  • Čemu služi HTML: HyperText Markup Language je jezik za označavanje koji definira strukturu i sadržaj web stranica.
  • Block vs. Inline elementi: Block elementi zauzimaju cijelu širinu i počinju u novom redu (<div>, <p>, <h1>); Inline elementi zauzimaju samo potrebnu širinu (<span>, <a>, <img>).
  • Objašnjenje taga <a href="https://google.com" target="_blank">Google</a>: href definira odredišni URL, target="_blank" otvara vezu u novom prozoru/kartici, a "Google" je klikabilni tekst.
  • Apsolutna vs. Relativna adresa: Apsolutna sadrži cjelovitu URL adresu uključujući protokol, dok relativna definira putanju u odnosu na trenutnu datoteku.
  • Sidro (Anchor): Poveznica koja vodi na specifični dio unutar iste stranice pomoću id atributa.
  • Spajanje ćelija u tablici: Atribut colspan spaja stupce, a rowspan spaja retke.

Primjer celovite HTML strukture s formom i tablicom:

<!DOCTYPE html>
<html lang="hr">
<head>
    <meta charset="UTF-8">
    <title>HTML Vježba</title>
</head>
<body>
    <h1 id="vrh">Naslov</h1>
    <table border="1">
        <tr>
            <td>Prva</td>
            <td colspan="2">Druga i treća</td>
        </tr>
    </table>
    <form action="#" method="POST">
        <label for="ime">Ime:</label>
        <input type="text" id="ime" name="ime" required>
        <button type="submit">Pošalji</button>
    </form>
</body>
</html>

3. CSS

  • Kaskadna primjena: Stilovi se primjenjuju hijerarhijski prema izvoru, specifičnosti selektora i redoslijedu pisanja.
  • Načini povezivanja CSS-a: Linijski (style="" atribut), Unutarnji (<style> tag u headu), Vanjski (<link rel="stylesheet" href="style.css">).
  • CSS Kombinatori:
    • div span: Svi span potomci unutar div-a.
    • div > span: Izravna djeca span unutar div-a.
    • div + span: Prvi susjedni span odmah nakon div-a.
    • div ~ span: Svi susjedni span elementi koji slijede nakon div-a.
  • Box Model: Content + Padding + Border + Margin.
  • box-sizing: content-box dodaje padding i border na zadanu širinu; border-box uključuje padding i border unutar zadane širine.
  • Pozicioniranje (position): static (normalni slijed), relative (relativno na svoj položaj), absolute (relativno na pozicionirani predak), fixed (fiksirano na prozor preglednika).

4. WordPress & SEO

  • Što je PHP: Skriptni jezik na strani poslužitelja (server-side) za izradu dinamičkih web stranica.
  • Tehnologije za WordPress: PHP, MySQL/MariaDB, HTML, CSS, JavaScript.
  • Cijena WordPressa: Softver sa stranice WordPress.org je potpuno besplatan i otvorenog koda (Open-source).
  • Promjena teme i sadržaj: Promjena teme mijenja samo vizualni izgled; sadržaj ostaje netaknut u bazi podataka.
  • Optimizirani SEO URL: Čitljiv i opisni URL (npr. /guitars/fender/jaguar) puno je bolji od URL-a s parametrima (/category=1&prod=2).
  • Preporučene duljine metatagova: Title tag: 50–60 znakova; Meta description: 150–160 znakova.
  • sitemap.xml vs. robots.txt: sitemap.xml popisuje stranice za lakše indeksiranje; robots.txt daje upute tražilicama koje dijelove stranice ne smiju pretraživati.
